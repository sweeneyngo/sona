How to use sona

Workflow

Load an annotation JSON and its vocal stem, then play the stem against the synthesized notes. Notes hard-snap to the grid live (set BPM · division · drag the ruler for phase); a confident off-grid note escapes snapping and is flagged. Fix flagged notes, add lyrics, then export MIDI, UST or USTX. Save writes a session JSON — reload it through the annotation input to resume editing exactly where you left off (MIDI can't do that: it keeps only the snapped notes).

Editing

Drag a note to move it (time + pitch), drag its right edge to resize, double-click empty space to add, select and press Delete to remove. Hover or click a note to see its confidence sub-scores.

Lyrics and UTAU export

Select a note and press L to type its lyric: Enter or Tab saves it and moves to the next note (Shift+Tab the previous), Esc stops. あ Lyrics pastes a whole text at once. UST (UTAU) and USTX (OpenUtau) export the same snapped notes as MIDI, with lyrics; a note without one sings あ. The notes move onto the editor's grid, so the vocal starts up to one grid cell earlier than the stem (the status line says how much).

Navigation

The roll shows ~2 octaves at a time. Scroll to move pitch, Shift-scroll to move time, ⌘/Ctrl-scroll to zoom (double-click the ruler to reset). Click the top ruler to seek; drag it to shift the grid phase.

Settings

Annotation / session JSON

The core's annotation, or a saved session to resume editing.

Vocal stem (audio)

Played against the synthesized notes. Any format the browser decodes.

Flag threshold 0.50

Notes below this confidence are outlined red for review. Calibrate by ear per song.

Musical key —

The key is auto-detected from the notes. Off: out-of-key notes are outlined for review. On: every note is snapped to the nearest scale tone (display + export). Purely interpretation — it never changes what was detected.

Lyrics

Paste the lyrics. They're split into one token per note: kana by mora (きゃ is one; ー, っ and ん are their own), romaji and English by word (write romaji morae with spaces: sa ku ra), each kanji on its own (paste kana for best results). Tokens fill notes in time order.

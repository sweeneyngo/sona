How to use sona

Workflow

Load an annotation JSON and its vocal stem, then play the stem against the synthesized notes. Notes hard-snap to the grid live (set BPM · division · drag the ruler for phase); a confident off-grid note escapes snapping and is flagged. Fix flagged notes, then export the corrected MIDI. Save writes a session JSON — reload it through the annotation input to resume editing exactly where you left off (MIDI can't do that: it keeps only the snapped notes).

Editing

Drag a note to move it (time + pitch), drag its right edge to resize, double-click empty space to add, select and press Delete to remove. Hover or click a note to see its confidence sub-scores.

Navigation

The roll shows ~2 octaves at a time. Scroll to move pitch, Shift-scroll to move time, ⌘/Ctrl-scroll to zoom (double-click the ruler to reset). Click the top ruler to seek; drag it to shift the grid phase.

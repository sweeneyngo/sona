# Note offsets are modeled by a Release sub-state, driven by an energy fall

**Extends [ADR-0010](0010-note-hmm-segmentation.md).** The pitch tracker (ADR-0005), energy-onset stage (ADR-0006), and the note-HMM's states/emission/interval prior are otherwise unchanged; this adds one sub-state to model where a note *ends*.

**Status: Rejected; code removed (audit A07, 2026-11-24).** The `Release` sub-state, its four `HmmParams` knobs, `NoteHmm::release_drop_threshold` and `sona-eval-release-sweep` are deleted, and the note-HMM is ADR-0010's three sub-states again (`stable_to_silent_frac` back to 0.5). Removing the off path was not byte-identical: `stable_to_release_frac = 0.1` still took transition mass and the decode could enter `Release` without the bonus. Vocadito gate (`sona-eval-report --corpus`, 40 stems), before → after: COnP-F1 0.6463 → 0.6466, COnPOff-F1 0.5077 → 0.5077, RPA and onset-F1 unchanged. One stem changed (vocadito_34, one more matched note); the song-bootstrap 95% interval of the baseline mean is ±0.034 (COnP) and ±0.040 (COnPOff). Grid mode, GAME and the cell stage don't use the note-HMM, so their output is unchanged. `reports/release-sweep.md` stays as the record.

**Status before removal: Accepted, but shipped OFF by default.** The capability and its knobs are implemented and unit-tested, but the corpus gate (`reports/release-sweep.md`) showed **no COnPOff gain on Vocadito** — every setting was neutral-to-harmful — so the default reproduces ADR-0010 exactly (`NoteHmm::release_drop_threshold = f32::INFINITY`). This is a real negative result, not a distribution artifact to explain away: the mechanism only helps where a note ends in a *sharp energy fall*, and that is not how most singing ends (see Consequences). It ships off because the evidence says a pure-DSP energy-fall release is not the offset fix. The knobs and the one-line enable are kept because the path is harmless when off and may still help inputs that genuinely do end in sharp cutoffs, but no favorable-corpus rescue is assumed.

## Context

The recorded note-HMM sweep ([ADR-0011](0011-evaluation-harness-vocadito-metrics.md), `reports/note-hmm-sweep.md`) puts corpus **COnP-F1 at 0.646 but COnPOff-F1 at only 0.508**: onsets and pitch land, offset precision is the measured bottleneck. This is the domain's known-hard sub-problem (CONTEXT.md: "offsets are the hardest sub-problem… acoustic decay ≠ musical note end").

Under ADR-0010 a note has no *model* of its own ending. It runs as a maximal voiced run and ends wherever the decode leaves `Stable` — to `Silent` (a rest) or to another pitch's `Attack`. `offset_kind()` then merely classifies that boundary and `drop_steepness()` measures the energy fall, both *after* the fact. Because pYIN's 2048-sample analysis window smears the voicing edge, the placed offset trails the true musical note end by a frame or two — and a note ending has no pitch signature to correct it with. The signal that *does* mark a note end is the **energy fall**, and the HMM already ignores it: energy enters only as the onset (rise) bonus on `Attack` (ADR-0006).

## Decision

Add a fourth left-to-right sub-state per pitch bin: **Attack → Stable → Release → Silent**.

- **Release** is a voiced, on-pitch **decay tail** — the same voiced emission mix as `Stable` at a tight σ (`sigma_release`, defaulting to `sigma_stable`). It is distinguished from `Stable` not by its emission but by an **energy-fall bonus**: at frames where the RMS envelope drops steeply (`drop_steepness ≥ release_drop_threshold`), every `Release` state's emission gets `release_offset_bonus`, drawing the decode `Stable → Release` exactly at the fall. This is the offset mirror of ADR-0006's onset-rise `Attack` bonus.
- **A note's offset is the `Stable → Release` boundary** — the musical note end. In the path→notes walk a `Release` frame is treated like `Silent` (not part of the note body), so the decaying energy sits in the gap before the rest and the emitted offset no longer trails the voicing smear.
- **Superset, not replacement.** `Stable → Silent` is kept, so a sharp staccato cutoff still goes straight to silence; the decay path engages *only* where the energy-fall signal fires. `Release` is **not** a note-change source — only `Stable` and `Silent` fan out to another pitch through the interval prior — so the dense `O(frames·bins²)` Viterbi is untouched; `Release` adds only `O(1)` incoming edges. `Stable`'s leave-mass now splits three ways (sharp cutoff / decay / note-change) with transition rows still normalised.

No dependency, FFT, or ML is added; this is pure DSP + dynamic programming, consistent with ADR-0005. The annotation JSON contract (ADR-0004), the `Segmenter`/`NoteSegment` seam, and the confidence formula (ADR-0008) are unchanged — offset-clarity still reads `drop_steepness`, only now at a better-placed offset.

## Rejected alternatives

- **Keep offsets post-hoc, just search harder for the energy drop.** That is what `offset_drop_steepness` already does (probe forward, take the steepest); it sharpens the *confidence signal* but cannot move the offset the decode committed to. The boundary has to be decided *inside* the Viterbi path to move, which is what the state does.
- **Give `Release` a distinct low-energy emission instead of a per-frame bonus.** The HMM's emission reads pitch + voicing, not energy; feeding a continuous energy term into emission would couple the model to absolute level and duplicate the onset stage's normalisation. A sparse per-frame bonus at detected falls matches the existing onset-splitter design and stays interpretable.
- **Force every note through `Release` (drop `Stable → Silent`).** Would push every staccato offset one frame early for no gain on the target material. Keeping both paths makes the change a strict superset.
- **Spectral-flux offsets (an FFT-based release detector).** More sensitive on legato/expressive material, but it retires the "no FFT" badge (ADR-0006) and adds a dependency. Deferred as a separate move; the energy-fall signal is the no-FFT first step and must prove out first.

## Consequences

- **This change is not eye-tunable and was gated by measurement**, exactly as ADR-0010 was. The Release sweep (`sona-eval-release-sweep`, `reports/release-sweep.md`) A/B'd the decay path on the 40-stem Vocadito corpus. Result: **no COnPOff-F1 gain** — the best setting was neutral (Δ −0.000, COnP +0.010) and every eager setting hurt (COnPOff down to 0.417). So the path ships **off**; the four `HmmParams` knobs plus `release_drop_threshold` are live but the default disables the path, and the enable defaults are the sweep's least-harmful (`release_offset_bonus = 12`, enable `release_drop_threshold ≈ 0.65`).
- **The mechanism has an intrinsic ceiling** the gate exposed. It can only tighten an offset where the note ends in a *sharp* RMS fall. Most singing does not end that way: expressive offsets are soft decays, breaths, or pitch-transitions with no steep fall, so the flag either never fires (no help) or fires on mid-note dynamics / vibrato dips and clips a real note (the harm seen as the threshold dropped). That ceiling is why the honest conclusion is that a pure-DSP energy-fall release is not the offset fix — the offset problem is the case the original bottleneck analysis flagged as best solved by a model trained with offset labels.
- **The golden fixtures already hold**: staccato offsets stay sharp (snapped to the energy fall, never pushed later), legato still splits at the pitch change, vibrato stays one note, bleed is still culled.
- **Confidence gets a better-placed input**, not a new formula: offset-clarity reads `drop_steepness` at the tightened offset.
- **Vocadito is a fair test here, not a discount.** It is real expressive singing — precisely the material whose soft offsets this mechanism cannot grab — so its verdict is the relevant one. A narrow slice of genuinely staccato input would show the Release path in a kinder light, but tuning or justifying the model around that slice would be overfitting to the one case where a weak mechanism happens to work. The offset bottleneck (COnPOff 0.508) stays open, to be attacked by a method that models note ends from more than an energy fall.
